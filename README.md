# Background
I am a new entrepreneur in medical device area. When I am working with AI agent, I need to feed it many documents, while most of documents are not created in .md format. I decided to create and save my documents in .md format so that AI agent can understand my instructions more efficiently.
I tried many editors, whil emost of them can not meet my requirmetns, so I decided to create an customized editor. All the codes are generated by AI agent.
If you are interested in this project, I am very glad to learn your advices.
# FinalMd
 FinalMd is an editor designed specifically for users who are unfamiliar with Markdown syntax. Users can create documents just as they would in a standard note editor, and the files are saved in .md format.
